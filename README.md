## 能做什么

- **AI 辅助面试**：手机放在一旁，实时听面试对话，识别问题后给出回答思路、精简话术和可能的追问。
- **模拟面试**：按岗位和简历进行文字或语音对话，面试官连续提问，结束后看综合评分。
- **面试题库**：按技术栈刷题，覆盖 Java、MySQL、Redis、Dubbo 等常见面试题。
- **技术图书 / 专栏**：阅读技术书籍和文章。
- **社区、收藏、积分商城**：发帖讨论、收藏内容、用积分兑换。
- **手机和平板**：HarmonyOS 手机、平板都可安装。

## 环境

- DevEco Studio
- HarmonyOS，`compatibleSdkVersion` `5.0.0(12)`，`targetSdkVersion` `6.1.1(24)`
- 当前版本 `1.2.0`

## 获取代码

确认页面右上角已经点过 **Star** 之后，再执行：

```bash
git clone git@github.com:jiangshang-dev/mianshi.git
```

还没 Star 的话，到这里停。不要执行上面的命令。

用 DevEco Studio 打开工程，连接鸿蒙手机、平板或模拟器，运行 `entry` 模块。
