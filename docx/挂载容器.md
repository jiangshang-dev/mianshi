不要把宣传页盖到容器里的 `/var/www/html/index.html` 上，那是 **Jeecg 管理后台**。宣传页放到子目录，和后台共存。

这个 Nginx 静态根目录是 **`/var/www/html/`**。你机器上文件已经在 `/home/docker/xuanchuan/`。

**1. 先拷进去（马上能访问）**

在服务器上执行：

```bash
docker exec jeecgboot-vue3-nginx mkdir -p /var/www/html/xuanchuan
docker cp /home/docker/xuanchuan/index.html jeecgboot-vue3-nginx:/var/www/html/xuanchuan/index.html
docker cp /home/docker/xuanchuan/promo jeecgboot-vue3-nginx:/var/www/html/xuanchuan/promo
```

浏览器打开：

- `http://103.233.254.223/xuanchuan/`
- 有域名、开了 443 就用 `https://你的域名/xuanchuan/`

**2. 想重启还在，改成挂载（推荐）**

正在跑的容器不能中途加 `-v`，要停掉再按原来的方式启动，并加上这一行：

```text
-v /home/docker/xuanchuan:/var/www/html/xuanchuan:ro
```

先看现在是怎么起的：

```bash
docker inspect jeecgboot-vue3-nginx --format '{{.HostConfig.Binds}}'
```

如果是 `docker run`，在原命令里加上面的 `-v`。如果是 compose，在 `jeecgboot-vue3-nginx` 的 `volumes` 里加：

```yaml
volumes:
  - /home/docker/xuanchuan:/var/www/html/xuanchuan:ro
```

然后：

```bash
docker compose up -d jeecgboot-vue3-nginx
```

改宣传页只要改宿主机 `/home/docker/xuanchuan`，刷新即可，不用再 `docker cp`。

**3. 打开 404 时**

Nginx 有 Vue history 回退，没找到文件会跳回后台 `index.html`。确认这两项都在：

- `/var/www/html/xuanchuan/index.html`
- `/var/www/html/xuanchuan/promo/logo.png`

地址要用带斜杠的 `/xuanchuan/`。
