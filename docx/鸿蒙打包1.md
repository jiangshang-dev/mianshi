上传失败是因为你打的是 **HAP**，应用市场要的是 **`.app` 包**。华为账号能不能登录，关键是：**正式包用的签名证书指纹，必须已经加到 AGC**。包名和 `client_id` 不要改。

当前工程还是 **调试签名**（`debugKey` / `default_mianshi_....cer`）。这个只能本机跑，不能上架。上架要另做一套**发布证书**，调试证书可以留着，两套指纹并存就不会把现在的登录弄挂。

---

**1. 先办发布证书和 Profile（只做一次）**

1. DevEco：`构建` → `生成私钥和证书请求文件`  
   别名填 `mianshi_release`（不要用 `debugKey`）
2. AGC → 证书管理 → 新增 **发布证书**，上传刚生成的 `.csr`，下载 `.cer`
3. AGC → Profile → 新增 **发布 Profile**
    - 包名必须是 `com.xiaobai.mianshi`
    - 选刚下的发布证书
    - 勾选 **华为账号服务 / Account Kit**
    - 下载 `.p7b`
4. DevEco：`File` → `Project Structure` → `Signing Configs`  
   配上发布用的 `.p12` / `.cer` / `.p7b`（和调试那套分开）

**2. 把发布证书指纹加进 AGC（登录不断的关键）**

AGC → 码上 Offer → SHA256 公钥指纹 → **再加一条**（发布证书那条）。

调试那条 `DF:21:A3:C0:...` **不要删**，本机调试登录还靠它。  
发布包用新证书，市场安装后登录靠新指纹。两边都在，互不影响。

这三样不要动：

- 包名 `com.xiaobai.mianshi`
- `module.json5` 里的 `client_id`：`6917614613964067859`
- 不要拿饭典 / 别的应用的证书来签这个包

**3. 打 `.app`，不要打 HAP**

不要用：`构建 entry 模块` / `assembleHap`（那是 `.hap`，AGC 会报你现在这个错）。

要用：

`构建` → `编译 Hap(s)/APP(s)` → **编译 App(s)** → 选 **release**

打完在工程里找：

`build/outputs/` 下面的 `*-signed.app`

把这个 `.app` 传到 AGC「上传包」。

**4. 上架前自测登录**

用 release 签名装到真机，点一次「华为账号登录」。能过，再传市场。如果报签名校验失败，就是发布指纹还没加进 AGC，等 1～2 分钟再生效。
